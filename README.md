# WebClient-UAS

Repositori ini berisi kumpulan file HTML dan CSS sebagai tugas praktikum kuliah untuk pembuatan web client dalam Ujian Akhir Semester (UAS). Proyek ini merupakan implementasi statis dengan tampilan yang disusun menggunakan HTML dan CSS.

## Deskripsi Proyek

Proyek **WebClient-UAS** merupakan tugas praktikum yang berfokus pada pembuatan antarmuka web statis. Di dalam repositori ini terdapat beberapa halaman yang masing-masing memiliki tema dan tampilan tersendiri, antara lain:

- **index.html:** Halaman utama yang menyajikan informasi dasar dan navigasi menuju halaman lainnya.
- **karakter.html:** Halaman yang berisi konten terkait “karakter” (misalnya, profil atau informasi mengenai karakter tertentu) beserta style khusus pada file `karakter-styles.css`.
- **ship.html:** Halaman yang berisi konten mengenai “ship” (mungkin informasi tentang kapal atau elemen serupa) dengan style tersendiri pada file `ship-styles.css`.

Selain itu, terdapat file CSS tambahan (`styles.css`) yang digunakan untuk menyempurnakan tampilan secara keseluruhan.

## Fitur

- **Halaman Statis yang Terpisah:** Terdapat halaman utama, halaman karakter, dan halaman ship.
- **Tampilan Responsif:** Penggunaan CSS untuk menciptakan tampilan yang menarik dan mudah dinavigasi.
- **Struktur Sederhana:** Kode HTML dan CSS disusun dengan rapi agar mudah dipahami dan dikembangkan.

## Cara Menjalankan Proyek

Karena proyek ini berupa website statis, Anda dapat menjalankannya secara lokal dengan langkah-langkah berikut:

1. **Clone Repository:**
   ```bash
   git clone https://github.com/rafly-id/WebClient-UAS.git
   cd WebClient-UAS
   ```

2. **Buka File HTML:**
   - Buka file `index.html` menggunakan browser favorit Anda.
   - Anda juga dapat mengakses halaman lain seperti `karakter.html` atau `ship.html` untuk melihat konten masing-masing.

3. **Live Demo:**
   Proyek ini juga telah dideploy, dan Anda dapat melihat hasilnya secara online di:  
   [web-client-uas-raflylucky.vercel.app](https://web-client-uas-raflylucky.vercel.app)

WebClient-UAS/
